This page reads live values straight from your Arduino's serial output — nothing is sent anywhere else.

  1. Plug in the Arduino via USB and make sure the sketch is uploaded and running.
  2. Close the Arduino IDE's Serial Monitor if it's open — only one program can use the port at a time.
  3. Click Connect device above and choose the Arduino from the browser's port list.
This browser doesn't support the Web Serial API. Open this page in Chrome or Edge on a desktop computer to connect to the Arduino.
